### 文件变更详情 / File Change Details

#### [修改 / Modified] `PhyAgentOS/cli/commands.py:L900-L1003`

**修改前 / Before:**

```python
agent_loop.set_long_horizon_controller(long_horizon_controller)
# The prompt_toolkit interactive presentation starts directly.
```

**修改后 / After:**

```python
agent_loop.set_long_horizon_controller(long_horizon_controller)
if ui == "textual":
    run_textual_app(
        agent_loop=agent_loop,
        bus=bus,
        controller=long_horizon_controller,
        coordinator=forge_task_coordinator,
        session_key=session_id,
    )
```

**修改说明 / Rationale:** Textual 仅接收已经创建的运行时对象，默认 prompt_toolkit 路径不变。Textual only receives already-created runtime objects, while the default prompt_toolkit path remains unchanged.
