### 设计边界 / Design Boundary

本次没有自动从普通聊天创建 AgentTask，也没有放宽 Forge Skill binding 要求。没有安装/运行 Forge Skill 时，系统仍会正确显示无任务提示；只有 Agent 沿既有 `forge_task_create` + primary Skill activation 路径成功落库后，Tasks / DAG 才会显示真实任务。

This change does not auto-create AgentTasks from ordinary chat and does not relax Forge Skill binding requirements. Without an installed/running Forge Skill, the dashboard correctly reports no task; a real Tasks / DAG row appears only after the existing `forge_task_create` plus primary Skill activation path persists a task.
