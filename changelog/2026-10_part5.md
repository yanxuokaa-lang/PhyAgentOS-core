- Two AgentTasks preparing different route geometry against the same static scene/frame collide in the legacy Adapter route identity and fail with `preparation reference already identifies different geometry`. The Core/Adapter checkout has the scoped URI helper, but installed Skill 3.0.13 still locks Node 1.0.3/SHA `7108b7e…`; the running process therefore cannot execute the new Adapter source. A Node artifact is an immutable release, so Git and source tests cannot change the installed Runtime lock. Publish a new Node version and reference it from a new Skill lock.
