### 失败场景依据 / Failure scenario
最近验收中 provider 在首个 task_creation/discovery 请求返回 `finish_reason=stop`、无内容且无 Tool call。AgentLoop 只对显式 `provider_timeout` 重试，因而没有调用 `activate_skill`/`forge_task_create` 或 task-bound Query，直接结束本轮；这会把可恢复的模型空响应误判为任务完成。
- In the latest acceptance, the provider returned `finish_reason=stop` with no content and no Tool call during the first task_creation/discovery request. AgentLoop retries only explicit `provider_timeout`, so it dispatched neither `activate_skill`/`forge_task_create` nor a task-bound Query and ended the turn; this misclassifies a recoverable empty model response as completion.
