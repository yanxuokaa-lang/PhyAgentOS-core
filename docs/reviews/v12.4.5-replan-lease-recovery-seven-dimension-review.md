# v12.4.5 Replan Lease Recovery Seven-Dimension Review

## 1. Architecture and Ownership

Pass. AgentLoop owns the beginning of a model decision turn and now claims the existing Coordinator lease at that boundary. Coordinator remains the sole owner of task status, deadline, revision, execution, and recovery events. CLI reaches the Coordinator through LongHorizonTaskController rather than SQLite.

## 2. Functional Correctness

Pass. The first awaiting-replan model turn receives one bounded extension before provider latency. An exact deadline-expired task can return to awaiting_replan under the same task ID without creating a revision or replaying a Tool.

## 3. Compatibility and Extension

Pass. Normal pause/resume behavior is unchanged. Existing ForgeTaskBeginRevisionTool lease claiming remains idempotent because replan_extension_used prevents a second extension. Tasks not failed by the exact deadline condition are rejected.

## 4. Robotics Safety

Pass. Recovery is control-plane only and requires no unsettled Action or Session. It grants neither motion authorization nor a planning binding. Freshness, calibration, workspace, collision, IK, Gateway, terminal-result, and post-Action observation requirements are unchanged.

## 5. State, Failure, and Recovery

Pass. Prior revisions, settlements, execution records, failure evidence, and task identity remain append-only. Cancellation, exhausted replan budget, unrelated failure, and in-flight execution reject recovery. The authorization reason is persisted as an event.

## 6. Tests and Observability

Pass. Tests prove lease timing, same-task restoration, preserved revisions, event creation, and unrelated-failure rejection. Focused pytest reports 91 passed; Ruff, compileall, CLI help, and git diff --check pass.

## 7. Maintainability and Release

Pass. The change reuses existing lease and controller boundaries and introduces no RGB-specific branch, direct database mutation, replacement task, digest, hash, or speculative schema. Review result: Blocker 0, Major 0.
