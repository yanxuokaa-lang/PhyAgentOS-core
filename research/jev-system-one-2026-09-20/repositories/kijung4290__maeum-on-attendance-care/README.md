# 마음온 — 어르신 출석 위험 모니터링

**공개 데모:** https://kijung4290.github.io/maeum-on-attendance-care/

어르신 프로그램의 최근 출석 흐름을 바탕으로 담당자가 먼저 확인할 대상을 보여주는 웹앱입니다. TypeSafe AI의 JEV API가 연결되면 선택지별 확률 판정을 사용하고, API 키가 없을 때는 더미 데이터와 로컬 규칙으로 모든 화면을 바로 시험할 수 있습니다.

## 바로 실행하기

Node.js 20 이상만 있으면 별도 패키지 설치 없이 실행됩니다.

```powershell
cd C:\Users\p7300\Downloads\Code\senior-attendance-risk
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다. 초기 상태는 **데모 분석 모드**입니다.

## XLSX 양식으로 실제 데이터 분석하기

로컬 서버의 **참여자 관리** 메뉴에서 다음 순서로 사용할 수 있습니다.

1. `① 양식 다운로드`로 XLSX 양식을 받습니다.
2. `출석입력` 시트에 참여자 정보와 회차별 출석 상태를 작성합니다.
3. `② 작성 파일 업로드`에서 작성한 XLSX를 선택합니다.
4. 검증이 끝나면 화면에서 로컬 판정 결과를 확인합니다.
5. `AI로 전체 다시 분석`을 눌러 업로드한 데이터를 JEV로 분석합니다.

출석 상태는 엑셀의 선택 목록에서 `출석`, `지각`, `결석`, `인정결석` 중 하나를 고릅니다. 최대 1,000명, 파일 크기 10MB까지 처리합니다. 업로드 자료는 메모리에만 유지되며 서버를 재시작하면 기본 더미 데이터로 돌아갑니다.

공개 GitHub Pages에서는 보안을 위해 업로드, 양식 다운로드, JEV 재분석 기능을 모두 숨기고 미리 생성된 가상 데이터의 결과만 보여줍니다.

테스트용 1,000명 파일은 `sample-data/가상_어르신_출석데이터_1000명.xlsx`에 있습니다. 모든 이름은 `가상참여자0001` 형식이며 실존 인물 정보가 아닙니다. 다시 생성하려면 `npm run generate:xlsx-1000`을 실행하세요. 1,000명 전체 JEV 분석은 많은 API 호출을 발생시키므로 사용량과 비용을 확인한 뒤 실행하세요.

## 실제 JEV API 연결

1. `.env.example`을 `.env`로 복사합니다.
2. TypeSafe 콘솔에서 발급한 키를 서버 환경 변수에 입력합니다.

```env
TYPESAFE_API_KEY=발급받은_키
PORT=4173
```

서버를 다시 시작하면 상단 배너가 `TypeSafe AI · JEV 연결됨`으로 바뀝니다. 화면의 **AI로 전체 다시 분석** 또는 상세 패널의 **이 참여자 다시 분석**을 누를 때 실제 API를 호출합니다. 키는 서버에서만 사용되며 브라우저 코드나 응답에 포함되지 않습니다.

## 포함된 테스트 데이터

`data/dummy-data.json`에는 2026년 8~9월 12회차를 기준으로 가상의 참여자 100명이 들어 있습니다.

- 안정적으로 참여하는 사례
- 사전 연락한 인정결석 사례
- 반복 지각과 간헐적 결석 사례
- 최근 출석률이 급격히 떨어진 사례
- 3회 이상 연속 무단결석 사례

이름, 연락처, 보호자 정보는 모두 가상이며 실제 인물과 무관합니다.

## 위험 판정 방식

JEV에는 이름과 전화번호를 제외한 최소 정보만 전송합니다: 익명 참여자 번호, 날짜별 출석 상태, 출석률, 최근 결석·지각 횟수, 흐름 변화, 담당자 메모. JEV의 `choice` 질문은 다음 세 값만 반환하도록 구성했습니다.

- `high`: 집중 확인
- `watch`: 관심 관찰
- `stable`: 안정

JEV 연결 전 데모 규칙은 연속 무단결석, 최근 4회 결석, 반복 지각, 출석률 하락을 가중 합산합니다. 인정결석은 위험도와 출석률 계산에서 제외합니다.

> 이 결과는 의료 진단이나 복지 조치의 자동 결정이 아닙니다. 연락·상담·사례관리 여부는 원자료와 실제 사정을 확인한 담당자가 결정해야 합니다.

## 테스트


테스트는 연속 결석 판정, 인정결석 처리, JEV 응답 정규화, 비정상 응답의 안전한 대체를 검증합니다.

## 주요 파일

- `server.js` — 정적 웹 서버, API 키 보호, JEV 호출
- `risk-engine.js` — 출석 지표 계산 및 데모 판정
- `docs/` — 반응형 대시보드 UI 및 GitHub Pages 공개 데모
- `data/dummy-data.json` — 가상 출석 데이터
- `test/` — Node 내장 테스트

## 공개 데모

GitHub Pages에서는 API 키를 노출하지 않기 위해 미리 생성한 100명의 로컬 데모 판정 결과를 표시합니다. 실제 JEV 호출은 `.env`가 설정된 서버에서만 동작합니다. 데이터를 다시 생성할 때는 다음 명령을 실행하세요.

```powershell
npm run generate:data
npm run build:static
```
