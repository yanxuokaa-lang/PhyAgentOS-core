# Beat Jev

A penalty shootout against TypeSafe Jev. Take turns shooting and keeping goal. One **Render Workflows** task owns the match, with scores saved in **Render Postgres**.

| Example    | Code and deploy                                                                                | Play                                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| TypeScript | <a href="typescript/README.md" target="_blank" rel="noopener noreferrer">TypeScript README</a> | <a href="https://beat-jev-typescript-web.onrender.com" target="_blank" rel="noopener noreferrer">Live game</a> |
| Python     | <a href="python/README.md" target="_blank" rel="noopener noreferrer">Python README</a>         | <a href="https://beat-jev-python-web.onrender.com" target="_blank" rel="noopener noreferrer">Live game</a>     |

Each example deploys its own web service, workflow, and paid Postgres database. They share the 3D frontend and game rules.
