# Jev experiments

Two small demos built with TypeSafe's Jev model:

- [Log analyzer](jev-log-analyzer/README.md) filters noisy logs for entries relevant to an incident. It includes synthetic checkout logs, a CLI, an MCP server, and tests.
- [Amith's Jev Routing Lab](jev-knowledge-router/README.md) scores knowledge bases and agents against a task. The React app is live at [jevrouting.demos.amithkk.dev](https://jevrouting.demos.amithkk.dev).

Each demo has its own setup instructions.
