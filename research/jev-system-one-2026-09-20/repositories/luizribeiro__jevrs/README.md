# jevrs

`jevrs` is a Rust client for TypeSafe AI's Jev (System One) API, designed around a portable sans-I/O core and strongly typed questions and answers.

Unlike `typesafe-rs`, `jevrs` prioritizes a sans-I/O core, typed handles and derives, and WASI support over a reqwest-and-tokio-only, stringly API.

**Status:** pre-alpha.
