# JevyChase

A little road trip through TypeSafe Jev’s structured decisions. TypeScript frontend, Vite, Hono, and Cloudflare Workers with an AI binding. Original generated vacation artwork lives in `public/roadtrip.png`.

## Run locally

Requires Node.js 22.12+ (or a supported newer LTS).

```sh
npm ci
npx wrangler login
npm run dev
```

Open http://127.0.0.1:8787. The local Worker calls the real Jev model through a remote AI binding. Live inference consumes AI Gateway credits; sample responses make no API calls. Wrangler watches Worker edits. For frontend hot reload, run `npm run dev:ui` in another terminal and open the Vite URL (API calls proxy to port 8787).

The account in `wrangler.jsonc` is Craig’s Cloudflare account. The dedicated `jevychase` gateway has authentication enabled. Worker bindings authenticate automatically; there are no model keys in the browser. Your account needs AI Gateway credits for live third-party model inference.

## What to try

- **Noul:** ask a yes/no question and move the threshold without another model call.
- **Choice:** edit category names/descriptions and inspect their probability distribution.
- **Score:** edit ordered descriptive levels and inspect the score, confidence, and distribution.
- Try road-trip, customer-support, and ambiguous states.
- Open **Under the hood** to edit the full request, including structured JSON state and mixed question types. While open, this editor overrides the form.
- **Use sample response** loads a fixed illustrative request and answer; it does not evaluate edited text.
- Restore or export the last 12 experiments from **Trip log**. Inputs and responses are stored locally in this browser. Clear the trip log to remove them.

## Validate

```sh
npm run types
npm run check
npm test
npm run dry-run
```

Binding/runtime types in `worker-configuration.d.ts` are generated by Wrangler, not handwritten. Frontend and Worker TypeScript configurations are separate to avoid DOM/Worker type collisions. Tests use Hono’s request interface with a mocked AI binding; live inference is a separate integration check. All three primitives were verified in one live request through the authenticated `jevychase` gateway. The adapter accepts both the documented direct result and the live binding’s `{ state: "Completed", result, gatewayMetadata }` envelope.

## Hosting

The app is deployed at [jevychase.craigsdennis.workers.dev](https://jevychase.craigsdennis.workers.dev). Sample mode is public. Live inference requires the shared `PLAYGROUND_TOKEN`, configured as a Worker secret. Enter that token in **Connection settings**; it is held in memory for the tab, not in browser storage. The deployment owner's copy is saved in the Git-ignored `.env.playground-access` file. The localhost development server needs no shared token and binds to loopback.

```sh
npx wrangler secret put PLAYGROUND_TOKEN
npm run deploy
```

The API validates the limited teaching schema, rejects cross-origin browser requests, caps bodies at 32 KB, and skips AI Gateway caching so repeat experiments can observe model variability. Gateway request/response logging is enabled. Use synthetic data for examples. A public multi-user service should use per-user identity and usage budgets instead of a shared token.
