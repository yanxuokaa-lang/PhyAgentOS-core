HOW IT WORKS / 数据来源

      
不是让模型生成 JSON，而是读取下一个 token 的分数。

      
当前实现使用原模型的语言模型输出头 lm_head，没有训练新的分类头，也没有生成计划、解释或答案 JSON。所有 JSON 键和结构由 Python 组装。

      
    
        
  1. 第一次 forward：共享前缀只编码公共 state 和通用指令（可包含图片），得到前缀缓存。问题 ID 和标准答案不进入模型。
    2. 
        
  2. 第二次 forward：独立分支复制前缀的 KV 与循环状态，每行仅输入自己的 instructions、criteria 和 Answer: 后缀。选项键映射为通过单 token 检查的内部字母代码（A、B…）；各分支看不到其他题目和答案。
    3. 
        
  3. 最后一层 → 输出头Qwen 文本解码器最后一个 block 的输出，经最终 RMSNorm（model.language_model.norm），再经线性词表投影 lm_head，得到 output.logits。不是 attention 权重或中间层打分。
    4. 
        
  4. 各行独立读出取每行最后一个真实输入 token（Answer: 的冒号）的候选 logits，再 softmax 和 argmax。候选 token 表示「空格 + 代码」。不是读取问题 ID 位置，也不生成任何答案 token。
    5. 
      

      

        
具体取哪个值？
# 第一次：共享前缀
base = model(prefix_ids, use_cache=True)
cache = replicate_cache(base.past_key_values, M)
# 第二次：仅输入十个独立后缀
output = model(suffix_ids, past_key_values=cache)
z = output.logits[i, suffix_lengths[i]-1, candidate_token_ids[i]]
# 等价于完整词表输出中：
# full_logits[i, lengths[i]-1, candidate_token_ids[i]]
p = softmax(z / temperature)
choice = original_keys[argmax(p)]
score = sum(i * p[i] for i in range(K))
noul = p[true_index]
confidence = (K * sum(p*p) - 1) / (K-1)
confidence 为 LitJev 的归一化 Gini 集中度（单选项时为 1），不是正确率，也不声称等于 Jev 的未公开公式。所有索引均从 0 开始；「空格 + 内部代码」必须在 Answer: 后恰好追加一个 token，否则拒绝请求。
查看 diagnostics.fields.*.provenance 获取本次实际层、序列位置和 token ID；不同请求不能照搬位置数字。

        
响应 JSON：哪些来自模型？
字段来源与含义

          
diagnostics.fields.*.logits直接取自模型。原 LM head 的候选词表 logits；转成 float32 后序列化。顺序见 provenance.candidate_labels / candidate_codes。

          
probabilitiesPython 计算：对候选 logits / T 做 softmax，不是模型口述的置信度，也不是完整词表概率。

          
choice / score / noulPython 计算：原键 argmax / 等级期望 / yes 概率。Noul 不额外返回 confidence。

          
confidencePython 计算的分布集中度。max_probability 另放在 diagnostics，二者不混用。

          
diagnostics.fields.*.provenance程序记录的层数、索引、绝对位置、词表 ID 和温度；不是模型生成。

          
type / model / usage来自输入类型、实际加载配置与程序计数；标准 usage 只有 input_tokens、output_tokens（0）。

          
diagnosticsLitJev 扩展：forward_calls（2）、calibration_fitted、timing、fields。标准 /v1/systemone 不返回这些字段。

        

      

      
标准请求：POST /v1/systemone，{model, state, questions}；标准响应：{model, answers, usage}。本页面使用 /v1/systemone/debug 获取计时和截图扩展。沿用 Qwen 原始 LM head、两次 forward，不宣称复现 Jev 的权重、内部架构或置信度数值。
